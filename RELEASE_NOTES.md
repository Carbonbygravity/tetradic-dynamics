# Normative analysis code update

This release adds the revised normative ΦID workflow. The revised workflow uses per-epoch Leader/Follower actor assignment, the recorded source inputs used for the revised ΦID analysis, and separate inference and controls for the four main contrasts and the genuine response-period × condition interaction. Four-contrast surrogate tiers use fixed parent-cluster direction in the finalization step; the initial upper-tail runner summary is not the reported result. Homologous and cross-hemispheric targets retain separate tiers.

The phasic documentation and script descriptions clarify response-period-onset alignment and the executed contrast definitions. Participant data and generated outputs are not included.

The published task-half script differs from the executed archived copy only in its auxiliary-file provenance hash list; estimation and statistical expressions are unchanged.
