# Normative analysis code

The normative ΦID workflow uses per-epoch Leader/Follower actor assignment and the recorded source inputs. Inference and surrogate controls are separate for the four main contrasts and the response-period × condition interaction. Four-contrast surrogate tiers use fixed parent-cluster direction in the finalization step; the initial upper-tail runner summary is not the reported result. Homologous and cross-hemispheric targets retain separate tiers.

The phasic documentation specifies how responses are aligned to response-period onset and how each contrast is defined. Participant data and generated outputs are not included.

The published task-half script differs from the executed archived copy only in its auxiliary-file provenance hash list; estimation and statistical expressions are unchanged.
