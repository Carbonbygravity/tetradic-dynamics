# Normative integrated information decomposition

`workflow/` contains the code for the harmonized normative ΦID findings reported in the revised paper. `historical/` preserves the earlier ΦID scripts; those scripts do not generate the revised primary findings. The release contains code, frozen target and decision records, an environment specification, and input-verification tools. It does not contain participant source data, generated tensors, null arrays, or reported output files.

The analysis uses 30 participant source-ROI HDF5 inputs from 15 dyads. Expected relative filenames, sizes, and SHA-256 hashes are recorded in `workflow/PhiID_Production_Preflight_2026-10-25/input_manifest.example.json`. A researcher with access to the inputs can create a local runtime manifest with `prepare_inputs.py` and compare it with the recorded inputs using `verify_inputs.py`. Runtime manifests contain local paths and should not be committed.

X denotes the task Leader and Y the Follower for each epoch: event suffix 1 assigns X=P1/Y=P2, and suffix 2 assigns X=P2/Y=P1. The event's L/F prefix identifies the sampled response period, not the identity of X. The four analysed persistence atoms are redundancy (`rtr`), Leader-unique information (`xtx`), Follower-unique information (`yty`), and synergy (`sts`). Time is measured relative to response-period onset.

Temporal inference treats the four main contrasts separately from the genuine response-period × condition interaction. Homologous and cross-hemispheric targets receive separate surrogate controls and robustness tiers. Geometry overlap is identified before those controls; it is not a third geometry-specific tier or a count of independent effects.

The final four-contrast control results are generated by `finish_controls.py` using each parent cluster's fixed direction for observed and surrogate values. The earlier upper-tail summary in the initial controls runner is not the reported tier result. See `REPLICATION_ORDER.md` for the execution order, dependencies, and verification limits.
