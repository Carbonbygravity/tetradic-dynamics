# Prepared inputs

**Behaviour.** Supply two screened, measured-only trial CSVs. Both require participant_id, role, condition and positive rt_ms. The normative input requires dyad_id. The clinical input requires group (HC, PT or SZ) and dyad_id or dyad. Use Leader/Follower and Matching/Mirroring labels. Preserve trial order and pairing. The reported model uses 14,626 normative and 13,736 clinical rows.

**Tonic EEG.** Supply the stage-82 directory with input_validation_complete.json and four subdirectories (primary, sensitivity_omit_dyads_1_4_14, combined_primary and combined_sensitivity_omit_dyads_1_4_14). Each contains model_metadata.csv and model_power.npz with raw_power and features in the validated order. The fitting code transforms raw power using log1p. Preserve response-event role_code and cond_code, within-participant rt_z, dyad/participant keys and actor_context. There are 68 regions and six bands. For the dyad jackknife, supply the model-run directory containing the verified inputs and completed fits.

**Paired phasic EEG.** Supply the harmonized clinical tensor and its validated manifests under 03_Results/Harmonized_Phasic_Run_01, anatomical adjacency and QA under 01_Source_Data and 05_Quality_Checks, and the projected-centroid adjacency reference under 03_Results/Normative_Cell_Order_Corrected_Run_01. Preserve participant identity, four-cell order, 68 parcels, bands and −1000 to +1000 ms time axis. These tensors already contain logged cell means. References inside private manifests must resolve to the verified inputs. Load historical pickle files only from trusted sources.

**Clinical associations.** Supply the frozen preflight directory with features.csv, clinical_scores.csv, test_inventory.csv, feature_metadata.json, original scripts checked by frozen_specification.json and original Results tables. The component directory supplies component_inputs.csv, specification.json, and component_results.csv. The clinical score workbook uses the Demographics_Emmanuel_CLEANED sheet, group and participant_id, ten PANSS items, panss_total, sofas_total_score, cog_dsst_written_score, cog_dsst_oral_score and verbal_fluency_num. Patient IDs must match the feature table and component inputs. Keep row order and test_id order unchanged. Patient and partner Leader-period mean log RTs are separate component inputs. All five clinical measures are available for all 15 patients.

**ΦID.** The production input is a matched pair of trial-level ROI arrays per dyad. Event labels and selections, ROI and band labels and time coordinates must align across partners. Source actor follows Leader/Follower assignment by block rather than file order. Preserve the frozen target identifiers, contrasts, geometry, window and surrogate gates. The between-cohort bootstrap uses frozen whole-dyad draws and separate main and interaction maximum-cluster families.
