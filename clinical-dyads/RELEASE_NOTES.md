# Clinical comparison

Adds analysis code for the patient–control study in a separate clinical directory. The behavioural model uses measured-only normative trials. The clinical association workflow reports the main analyses and the separate response-period × condition interaction. The initial package covers selected analyses from prepared inputs, including participant-level phasic comparisons and the theta dyad-omission sensitivity. Upstream preprocessing and full raw-to-results reproduction require further release components.

Includes the ΦID tile calculation and source functions for contrast construction, surrogate generation, embedding and direct cohort comparison. The bundled phyid backend retains its BSD 3-Clause licence.

See WORKFLOWS.md for covariance sensitivity, ΦID selection and controls, and the scripts behind Supplementary Tables ST12–ST16.
